# 中小型商家 AI 数据分析工具
## 一、项目概述
### 1.1 项目介绍
本项目是一款面向中小型商家的轻量化 AI 数据分析工具，基于 Streamlit + Pandas + Plotly + OpenAI API 开发，支持商家上传 Excel/CSV 数据文件，通过自然语言提问自动完成销售数据分析、可视化图表生成、经营建议输出，无需专业数据分析能力即可使用，核心解决中小型商家 “数据看不懂、不会分析、分析耗时久” 的经营痛点。
### 1.2 核心功能
- 数据上传与自动解析（支持 Excel/.xlsx、CSV 格式）
- 自然语言提问转 AI 智能分析（无需专业术语）
- 自动生成柱状图 / 折线图 / 饼图可视化图表，支持交互
- 基于分析结果输出可落地的经营建议
- 分析历史记录留存与结果一键复制
- 完善的异常提示与操作引导

### 1.3 技术栈
- 开发语言：Python 3.8+

- 前端框架：Streamlit（快速搭建交互式 Web 页面）
- 数据分析：Pandas、NumPy（数据处理与计算）
- 数据可视化：Plotly（交互式图表生成）
- AI 能力：OpenAI GPT API（自然语言理解、分析代码生成）
- 辅助工具：文件解析、代码沙箱执行、异常处理、页面样式美化

## 三、核心文件详细说明
### 3.1 app.py
- 核心作用：项目启动入口，负责前端页面渲染、用户交互、结果展示主要职责：
- 加载页面样式、设置标题与整体布局
- 提供文件上传组件，完成 Excel/CSV 文件的解析与数据缓存
- 实现自然语言提问输入框与分析触发按钮
- 承接分析结果，分区域展示文本结论 + 可视化图表 + 经营建议
- 展示用户分析历史记录，支持结果复制
- 统一处理前端交互的基础异常提示

### 3.2 analysis.py
核心作用：项目核心业务逻辑模块，串联 “提问→分析→生成→输出” 全流程关键核心函数：

|函数名|核心功能|
|:---:|:---:|
|generate_analysis_code|	接收用户提问与数据列名，调用 OpenAI API 生成符合规则的 Pandas 分析代码|
|generate_visualization|     根据提问类型与分析结果，自动匹配生成 Plotly 柱状图 / 折线图 / 饼图|
|generate_business_advice|	基于分析结果与零售行业规则，输出简洁可落地的经营建议|
|handle_analysis|	分析流程总入口，完成前置校验、加载状态、代码执行、结果存储全操作|

核心规则：	
- AI 生成代码固定数据框变量为df，最终结果必须赋值给result
- 利润默认计算规则：销售数量 × 单价 ×0.3
- 可视化图表根据提问关键词自动匹配，无匹配关键词时不生成图表

### 3.3 utils.py
- 核心作用：通用工具函数封装，提供全项目可复用的基础功能主要功能：
- 代码清洗：过滤 AI 生成代码中的无效内容，保证可执行性
- 结果格式化：统一数值、文本的输出格式，提升可读性
- 历史记录管理：实现分析记录的添加、查询、缓存
- 异常提示封装：统一项目的错误提示文本与展示样式
- 数据基础校验：简单校验上传数据的关键字段完整性

### 3.4 config.py

核心作用：项目全局配置文件，主要用于 OpenAI API 客户端初始化核心配置内容：
```python
from openai import OpenAI
# 初始化OpenAI客户端
client = OpenAI(
    api_key="此处填写你的OpenAI API Key",  # 核心配置项
    base_url="https://api.openai.com/v1"    # API基础地址，无需默认可不改
)
```
### 3.5 styles.py
- 核心作用：页面 UI 样式美化，自定义 Streamlit 默认样式，提升用户体验主要美化内容：
- 自定义页面宽度、背景色、字体大小
- 优化按钮、输入框、卡片的样式与 hover 效果
- 美化可视化图表、分析结果的展示布局
- 调整历史记录、异常提示的样式，使其更贴合商家使用场景

### 3.6 其他目录说明
- pages/：Streamlit 多页面扩展目录，可用于二次开发添加“帮助中心”“数据模板”等页面
- .streamlit/：包含 config.toml 文件，可配置 Streamlit 页面主题、运行端口、菜单等
- pycache/ & .idea/：自动生成的缓存 / IDE 配置文件，无需编辑，可忽略

## 四、快速启动指南
### 4.1 环境准备
确保本地安装Python 3.8 及以上版本，未安装的可从Python 官网下载安装。
### 4.2 安装项目依赖
打开终端 / 命令行，进入项目根目录（DataAnalysis/），执行以下命令安装所有依赖：

```python
pip install pandas numpy plotly streamlit openai
```
### 4.3 配置 OpenAI API Key
打开项目根目录下的config.py文件
将api_key后的引号内替换为你的 OpenAI API Key（需自行在 OpenAI 平台申请） 保存文件，配置完成

### 4.4 启动项目
在项目根目录的终端 / 命令行中，执行以下启动命令：
```python
streamlit run app.py
```
### 4.5 访问使用
启动成功后，终端会输出访问地址，默认打开浏览器访问：http://localhost:8501即可进入工具主页面，开始使用。

## 五、工具使用流程
- 文件上传：点击页面上传按钮，选择本地的销售数据 Excel/CSV 文件（建议包含商品名称、销售数量、销售日期、单价等关键字段）
- 数据解析：等待系统自动解析数据，解析成功后会提示数据基本信息
- 问题提问：在输入框中用日常语言输入分析需求，无需专业术语
- 开始分析：点击【开始分析】按钮，等待系统完成 AI 分析、图表生成
- 查看结果：在页面结果区查看文本分析结论 + 可视化图表 + 经营建议
- 后续操作：可复制分析结果、查看历史分析记录，或重新上传文件 / 提问
- 示例提问

> 1. 销量最高的商品是什么？
> 2. 近 7 天的销量趋势如何？
> 3. 各商品类别的销量占比是多少？
> 4. 计算本月的总利润和客单价
> 5. 找出销量 TOP5 的商品

## 六、支持的功能类型
### 6.1 支持的分析类型
- 基础统计：销量 / 利润 / 客单价的总和、平均值、最大值、最小值
- 排名分析：商品按销量 / 利润的 TOP 排名
- 趋势分析：按日 / 周 / 月的销量 / 利润变化趋势
- 占比分析：商品类别 / 规格的销量 / 利润占比
- 简单对比：不同时间段 / 类别的数据对比

### 6.2 支持的可视化图表

|图表类型	|适用分析场景	|触发关键词|
|:---:|:---:|:---:|
|柱状图	|商品排名、数据对比	|最高、最低、TOP、排名、对比|
|折线图	|时间趋势、数据变化	|趋势、每天、每周、每月、变化|
|饼图	|类别占比、结构分布	|占比、比例、分布、构成|

### 6.3 经营建议生成规则
- 系统会根据分析结果，结合零售 / 电商行业通用规则，输出每条≤20 字、可落地的建议，核心规则：
- 销量高 / 趋势上涨 → 建议增加进货量、重点推广
- 销量低 / 趋势下跌 → 建议促销清库存、排查原因
- 占比集中 → 建议优化产品结构、补充同类爆款
- 利润偏高 → 建议保持定价、扩大推广
- 利润偏低 → 建议优化成本、调整定价
- 数据异常波动（超 50%）→ 建议排查库存、物流、差评等问题

## 七、常见问题与解决方案
### 7.1 项目启动失败
- 现象：执行启动命令后报错，无法打开页面
- 可能原因：Python 版本低于 3.8、依赖未安装完成、端口被占用
- 解决方案：
  1. 检查 Python 版本：执行python --version确认≥3.8
  2. 重新安装依赖：执行pip install --upgrade pandas numpy plotly streamlit openai
  3. 更换端口启动：执行streamlit run app.py --server.port 8502

### 7.2 API 相关报错
- 现象：点击分析后提示 “API 调用失败”“Key 无效”
- 可能原因：API Key 填写错误 / 过期、账户无余额、网络无法访问 OpenAI
- 解决方案：
  1. 核对config.py中的 API Key 是否正确，无空格 / 错别字
  2. 登录 OpenAI 平台，检查账户是否有余额、API Key 是否有效
  3. 检查网络环境，确保能正常访问 OpenAI 接口

### 7.3 分析失败 / 无结果
- 现象：点击分析后提示 “分析失败”，无结论 / 图表
- 可能原因：数据缺少关键字段、文件格式异常、提问表述模糊、AI 生成代码错误
- 解决方案：
  1. 检查上传数据，确保包含商品名称、销售数量、日期等核心字段
  2. 确保文件为标准 Excel (.xlsx) 或 CSV 格式，无乱码、无合并单元格
  3. 优化提问表述，使其清晰无歧义（参考示例提问）
  4. 刷新页面后重新上传文件、提问

### 7.4 无可视化图表生成
- 现象：有分析结论，但无图表展示
- 可能原因：提问无匹配的图表关键词、数据无时间 / 类别等维度
- 解决方案：
  1. 在提问中加入图表触发关键词（如趋势、占比、排名）
  2. 检查数据是否包含日期、商品类别等图表所需维度字段

### 7.5 页面样式错乱
- 现象：页面布局混乱、按钮 / 输入框样式异常
- 可能原因：styles.py 文件被修改、Streamlit 版本过低
- 解决方案：
  1. 恢复 styles.py 文件的原始内容
  2. 升级 Streamlit：执行pip install --upgrade streamlit

## 八、注意事项
- 敏感信息保护：config.py文件包含 OpenAI API Key，使用时务必注意个人信息泄露。
- 数据文件规范：建议上传的文件单文件≤10MB、数据行≤10000 行，字段清晰、无乱码、无合并单元格，提升分析成功率。
- API 成本控制：免费版 OpenAI API 有额度限制，建议优化提问方式，避免重复无意义的分析，减少 API 调用。
- 二次开发说明：可基于pages/目录扩展多页面，基于analysis.py增加更多分析类型 / 图表类型，基于styles.py自定义页面样式。
- 数据安全：本工具仅在本地会话中缓存上传数据，关闭页面后自动清除，不存储任何用户原始数据，可放心使用。
